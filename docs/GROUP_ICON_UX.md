# 프로젝트 그룹 아이콘 선택

그룹은 회사·고객사·제품·기술 스택처럼 프로젝트를 묶는 기준이다. 서비스의 내부 리소스까지 아이콘 목록에 노출하면 선택 비용만 늘어난다.

## 선택 목록

- AWS: 대표 서비스 25개. 컴퓨팅, 데이터, 네트워크, 메시징, 운영으로 구분한다. EC2 인스턴스 세부 유형과 개별 리소스는 새 선택 목록에서 제외한다.
- 금융·결제: 서로 다른 브랜드 26개. 국내 은행·금융, 결제·핀테크, 글로벌 금융·결제로 구분한다.
- 개발 도구: 인프라·운영, 백엔드·데이터, 앱·협업으로 구분한다.
- 기본 아이콘: 회사, 개인, 서버, 데이터베이스, 테스트, 모바일, 디자인처럼 로고가 없는 그룹에 사용한다.
- 검색은 정리된 목록 전체에서 찾는다. 이전에 저장한 비추천 아이콘은 현재 그룹 편집에서만 유지해 보여준다.

## 색상

로고가 있는 항목은 대표색을 자동 적용한다. 색상 선택 팔레트를 숨겨 불필요한 결정을 줄이며, 원본 로고 자체를 재색칠하지 않는다. 자동 적용 색상은 작은 색상 표시와 설명으로 확인한다.

기본 아이콘은 사용자가 색상을 고른다. 로고를 골랐다가 기본 아이콘으로 돌아오면 이전에 고른 수동 색상이 복원된다. 기존 저장 형식을 유지하고 화면에서 로고 대표색을 계산하므로 그룹 이름·경로·수동 색상은 손실되지 않는다.

## 자산과 검증

기존 세부 AWS 아이콘은 저장된 그룹을 깨뜨리지 않도록 파일과 ID를 보존한다. 신규 금융 로고는 출처가 확인된 자산만 추가한다. GLN과 토스는 원본 PNG를 사용하며 SVG로 표시하지 않는다. 전체 출처는 GROUP_ICON_SOURCES.md에 기록한다.

검증: 서비스 수 제한, 섹션 분류, 브랜드 자동 색상, 기본 아이콘 색상 복원, 저장·재시작, 이전 아이콘 유지, 금융 로고 중복, 작은 창과 밝은/어두운 테마.


## 금융그룹 중심 선택
금융 아이콘은 국내 금융그룹 → 글로벌 금융그룹 → 기타 금융기관 → 결제·핀테크 순서로 제공합니다. 하나·KB·신한·우리·NH·BNK·JB·삼성금융은 은행별 중복 항목 대신 그룹 단위로 선택합니다. 기존 아이콘 ID와 파일은 유지해 저장된 설정을 보존합니다. 은행·계열사 이름은 검색 별칭에 포함합니다. 프로젝트 그룹의 사용자 지정 이름은 자동 변경하지 않습니다. 공유하는 심볼은 그대로 사용하며 로고를 임의로 재색칠하지 않습니다.
