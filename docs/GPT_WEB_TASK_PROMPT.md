# pGit 후속 작업 요청 프롬프트

아래 내용을 복사하고 작업 요청을 채운다. `GPT_HANDOFF.md`와 현재 소스 또는 접근 가능한 저장소를 함께 제공한다. 문서만 전달하면 현재 파일 전체를 확인한 구현·검증은 할 수 없으므로 소스 접근 여부부터 확인해야 한다. 스크린샷은 문제 화면이 있을 때 함께 제공한다.

```text
pGit 개발을 이어서 진행해줘.

저장소: https://github.com/Polar-Little-Lab/pGit
기준 브랜치/커밋: [현재 main의 커밋 또는 첨부 소스 기준]
이번 요청: [수정할 기능과 기대하는 동작]
재현: [클릭 순서, 실제 결과, 기대 결과, 필요하면 스크린샷]

첨부 GPT_HANDOFF.md의 제품 원칙과 구현 구조를 먼저 읽어줘.
소스의 AGENTS.md 등 적용되는 지침과 현재 변경 상태도 확인해줘.
기존 구현을 확인하고 실제 수정까지 진행해줘. 이 문서의 오래된 커밋이나 로컬 절대 경로를 그대로 가정하지 마.

핵심 기준:
- 선택한 대상을 다시 묻는 불필요한 모달/단계를 늘리지 않는다.
- 커밋 선택은 정보가 있는 목록을 사용한다.
- 주요 실행은 명확한 텍스트 버튼, 새로고침 등 보조 동작은 접근 가능한 아이콘.
- 그룹은 탭/홈에서 이름·색상·아이콘으로 구분하며 재시작 후 유지한다.
- 저장소 URL 변경 시 상위 폴더를 유지하고 대상 폴더명을 자동 갱신한다.
- 사용자 변경·스테이징·초안과 기존 저장소를 보존한다.
- 앱 문구 6개 언어와 Windows/macOS 경로를 고려한다.
- 외부 댓글 게시, 이력 재작성, 실제 저장소 삭제를 검증 목적으로 임의 실행하지 않는다.

변경과 관련된 테스트를 실행하고 UI는 직접 확인해줘.
완료 시 변경 요약, 테스트 결과, 남은 제한, 수정 파일 또는 적용 가능한 diff를 전달해줘.
소스 접근이나 실행 도구가 없으면 그 범위를 분명히 하고 구현/테스트/배포했다고 주장하지 마.
커밋·push·릴리스 발행은 이번 작업에서 지정한 범위 안에서 수행해줘.
```

## 요청 예시

```text
프로젝트 그룹을 접었다 펼칠 수 있게 개선해줘.
AWS 그룹 안의 api/web 탭이 하나의 그룹 제목 아래에서 펼쳐지고,
다른 그룹으로 전환해도 각 프로젝트의 편집 상태가 유지되어야 해.
현재 그룹 색상·아이콘·필터·저장 형식과 호환되게 해줘.
변경 후 그룹 접기/펼치기, 키보드 이동, 앱 재실행 복원을 테스트해줘.
```

이 예시는 다음 작업 요청을 작성하는 방법이며, 그룹 접기 기능이 현재 구현되었다는 뜻은 아니다.
