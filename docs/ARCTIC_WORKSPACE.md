# Arctic workspace · pGit 0.4

GitKraken의 프로젝트 탭·그래프 중심 탐색·스테이징 패널 작업 방식을 참고하여 pGit의 기존 Git 엔진 위에 새 데스크톱 작업 공간을 구성합니다. 브랜드와 화면은 Polar Frost로 유지합니다.

## 화면과 동작

- 상단 프로젝트 탭과 `+` (드래그로 순서 변경): 로컬 저장소 열기, 원격 복제, 새 저장소 초기화.
- 같은 저장소는 실제 경로로 비교하여 기존 탭에 포커스합니다.
- 왼쪽: 브랜치 검색, 이력 범위, 원격·태그·stash.
- 중앙: 전체 높이의 그래프. 브랜치/태그 라벨과 그래프를 메시지와 분리합니다. 커밋 파일을 누르면 중앙에 Diff를 열고 돌아가기 버튼으로 그래프에 복귀합니다.
- 오른쪽: 커밋 이력에서는 선택한 커밋의 작성자·부모·변경 파일만 표시합니다. 변경사항 메뉴에서만 스테이징 목록과 커밋 폼을 표시합니다. 부모 커밋 이동과 merge 부모별 비교를 지원합니다. 좌우 패널은 드래그/방향키로 너비를 조절합니다.
- `⌘T / Ctrl+T`: 프로젝트 추가. `⌘W / Ctrl+W`: 현재 프로젝트 탭 닫기. 작업 공간 안의 `Ctrl+Tab`: 다음 프로젝트. 탭 목록에서는 좌우/Home/End 키로 이동.
- 탭 전환은 파일 선택·검색·커밋 초안을 보존합니다. 초안이 있는 탭 닫기는 확인합니다. 파일 변경과 인덱스는 닫아도 유지됩니다.

## 요청 격리

각 탭은 유지되는 iframe 작업 공간과 불투명한 workspaceId를 가집니다. 서버는 workspaceId → 실제 저장소 경로를 별도로 보관하며 요청 시작 때 root를 캡처합니다. 한 탭의 열기나 전환으로 다른 탭의 Git 대상이 바뀌지 않습니다.

같은 workspaceId와 같은 실제 저장소에 겹치는 요청은 거부합니다. 서로 다른 저장소는 별도로 처리합니다. 이전 단일 전역 root는 제거했습니다. Host, Origin, 세션 토큰 검증은 유지합니다. Shell/작업 공간 메시지는 origin과 source 창을 모두 확인합니다. 네이티브 폴더 선택기와 저장 API는 최상위 신뢰 프레임에만 허용합니다.

## 복원

데스크톱은 userData의 arctic-workspace.json에 열린 경로·활성 경로·최근 경로만 저장합니다. 저장 입력은 정규화하고 중복·잘못된 경로를 제거하며 임시 파일을 rename하여 교체합니다. 커밋 메시지와 diff 내용은 저장하지 않습니다. 브라우저는 동일 서버 origin의 localStorage를 사용합니다.

## 디자인 시스템

Polar UI 0.1.0 `tokens/frost.json`의 색상·간격을 `public/frost.css`에 반영했습니다. 기존 앱은 vanilla DOM이므로 React 컴포넌트를 도입한 것으로 간주하지 않습니다. 의미 있는 라벨, 2px 포커스, 비활성 상태, 버튼 역할 등 공통 계약을 따릅니다. 데스크톱 밀도를 위해 아이콘+라벨 도구 모음은 56px, 보조 액션은 25–30px이며 폼 컨트롤은 40px입니다. 시작 화면의 빙하 일러스트는 앱 전용 SVG입니다.

## 검증

- 로컬 Git 테스트: 같은 파일명을 가진 두 저장소의 동시 읽기와 Stage/Commit 분리, 탭 닫기 후 다른 저장소 유지.
- 저장 테스트: 정규화, 중복 제거, 초안 미저장, 순차 원자적 쓰기, 손상된 JSON 복구.
- UI 테스트: 기존 Git 흐름 및 +/프로젝트 전환/초안 보존/중복 방지/닫기 확인/복원/단축키.
- 테스트 결과 이미지는 test-results/arctic-home.png, arctic-tabs.png 등에 저장합니다.

## 남은 범위

GitKraken의 모든 기능을 구현한 것은 아닙니다. 원격 브랜치 드래그 작업, 영구 커밋 초안, 프로젝트 그룹, 다중 커밋 작업, 범용 Undo/Redo, 파일 감시 자동 갱신, 다크 테마와 외부 호스팅 연동 확장은 남아 있습니다. 프로젝트마다 유지되는 렌더링 컨텍스트가 있으므로 수십 개 저장소 동시 사용의 메모리 성능은 별도 측정이 필요합니다.

## 선택 메뉴와 일상 작업

- 브랜치·원격·Stash·비교 부모·리베이스 동작 선택은 검색 가능한 Frost 메뉴입니다. 방향키/Enter로 선택하고 Escape로 메뉴만 닫습니다.
- 전체 스테이징/전체 해제와 ⌘/Ctrl+Shift+S/U를 지원합니다. 충돌 중에는 실행하지 않으며 작업 파일을 삭제하지 않습니다.
- 커밋 제목과 상세 설명을 분리해 작성하고 ⌘/Ctrl+Enter로 스테이징한 내용만 커밋합니다. 제목 72자는 권장 길이 표시이며 전체 메시지는 4,000자로 제한합니다. 상세 설명도 탭 초안 보호와 커밋 상세에 포함됩니다.
- 로컬 브랜치를 현재 브랜치 위에 드롭하면 병합 또는 리베이스의 방향을 검토하고 기존 실행 폼을 엽니다. 현재 브랜치가 아닌 대상에는 먼저 체크아웃을 안내합니다. 드롭 자체는 Git을 변경하지 않습니다.

## 언어와 용어

상단 언어 버튼으로 한국어/영어를 즉시 전환합니다. 열린 탭에 동일하게 적용하며 데스크톱 설정 파일에 언어를 저장합니다. UI 번역은 `public/i18n.js`에 모으며 브랜치·파일·작성자·커밋 메시지·Diff·Git 출력은 원문을 유지합니다. 외부 Git/CLI에서 반환한 오류는 원문으로 표시될 수 있습니다.

한국어 Stash 용어는 스태시 저장 / 스태시 적용 / 스태시 적용 후 삭제 / 스태시 삭제로 통일합니다. 영어는 Stash / Apply Stash / Pop Stash / Drop Stash입니다. Pop은 단순 적용과 구분되며, 기존 Git 작업을 그대로 호출합니다. 언어 전환은 입력 중인 커밋 초안을 바꾸지 않습니다.

## IntelliJ 스타일 Diff

과거 커밋과 작업 폴더 모두 같은 읽기 전용 좌우 코드 뷰어를 사용합니다. SQL 및 JS/TS/JSON/Python 등의 기본 어휘 구문 색상, 변경 단어 강조, 중앙 변경 연결선, 안쪽 줄 번호, 변경 위치 막대, 동기 스크롤, Alt+위/아래 변경 이동을 제공합니다. 언어 서버나 IntelliJ의 구문 분석 엔진을 사용하는 것은 아닙니다.

`줄 내 공백 무시`는 공백·탭만 다른 줄의 강조를 숨기는 보기 옵션입니다. Git 인덱스나 커밋 내용은 변경하지 않습니다. `변경 없는 줄 접기`는 변경 없는 구간을 접고, 접힌 줄 수를 눌러 펼칩니다. 통합 Diff도 선택할 수 있습니다.

작업 중 영역은 인덱스와 작업 파일, 스테이징 영역은 HEAD와 인덱스를 비교합니다. 비교용 콘텐츠를 먼저 캡처하고 임시 파일에서 patch를 계산해, 서로 다른 Git 영역을 섞지 않습니다. 바이너리·큰 파일·심볼릭 링크는 명시적으로 처리합니다. 블록/줄 스테이징과 편집은 기존 변경 검증 흐름을 유지합니다.

통합 보기는 원시 patch 대신 한 코드 화면에 이전/이후 줄 번호를 표시합니다. 변경 블록마다 삭제 줄(빨강, −) 다음에 추가 줄(초록, +)을 보여주며 변경 없는 줄은 한 번만 나타납니다. `바뀐 부분 강조`와 `변경 없는 줄 접기`는 두 보기에서 모두 동작하고 마우스/키보드 포커스 시 설명을 제공합니다.

## 이력과 변경사항 분리

커밋 이력은 기록된 커밋과 그 Diff를 탐색하는 화면입니다. 미커밋 변경 안내나 이동 링크는 표시하지 않습니다. 작업 중인 변경은 왼쪽 변경사항 메뉴에서 확인합니다. 커밋이 없거나 검색 결과가 없으면 상세 패널에 빈 상태를 표시합니다.

스테이징·작업 파일 Diff·커밋 제목/설명은 변경사항 메뉴에만 표시합니다. 화면 이동 중 초안과 파일 선택은 보존하며, 커밋/전체 스테이징 단축키는 변경사항 화면에서만 처리합니다.

브랜치는 `/` 접두사별로 접고 펼칠 수 있습니다. 로컬·원격 브랜치 영역도 각각 접을 수 있고 새로고침 중 접힘 상태를 유지합니다. 사이드바의 중복 검색창은 제거하고 상단 브랜치 전환 메뉴에서 검색합니다. 작업 대상은 항상 전체 Git 참조를 유지합니다. 동기화 버튼은 두 언어에서 Fetch / Pull / Push를 사용하고 툴팁으로 차이를 설명합니다. 공백 비교는 `공백 포함` / `줄 내 공백 무시` 버튼으로 선택합니다.

## 공통 컨트롤

`public/controls.css`는 프로젝트 홈과 작업 공간이 함께 사용하는 컨트롤 규칙입니다. 보기 방식·공백 처리·Git 영역은 분할 선택 버튼, 강조·접기·스크롤 동기화는 독립 토글로 표현합니다. 토글은 선택 색과 체크를 함께 표시하고 통합 보기에서는 동기화를 비활성화합니다. 도구 모음은 28px, 입력 폼은 36px 높이를 사용하며 테두리·모서리·포커스·비활성 상태는 공유합니다. 사이드바의 모든 접힘 표시와 브랜치 아이콘은 동일한 SVG를 사용합니다.

## 설정과 모달

상단 설정에서 한국어/영어 및 밝게/어둡게/시스템 테마를 선택합니다. 모든 열린 프로젝트에 적용되며 데스크톱 workspace 저장 파일에 유지합니다. 상단 언어 버튼과 POLAR / FROST 표시는 제거했습니다. 커밋 검색 수치는 현재 브랜치 범위의 결과 수/대상 수를 반영합니다.

짧은 작업 메뉴는 340px, 일반 입력 모달은 460px, 편집기는 940px를 기준으로 창 크기에 맞게 제한합니다. 일반 모달은 내용 높이로 중앙 정렬하고, 작업 검색은 위쪽에 배치합니다. 비교 편집기만 큰 캔버스를 유지합니다. 브랜치 영역의 자식도 동일한 들여쓰기 규칙을 따릅니다.
