# pGit 1.3.0

## 변경 사항

- 설정 → 앱 정보에서 **새 버전 다운로드**를 눌러 설치 파일을 앱 안에서 받을 수 있습니다. 운영체제와 아키텍처에 맞는 파일을 선택하며, Apple Silicon에서 Intel 앱을 실행 중인 경우에도 ARM64 파일을 선택합니다.
- 다운로드 진행률과 용량, 취소·재시도, 완료 후 **설치 파일 열기**와 **폴더에서 보기**를 제공합니다. 설정 화면을 닫아도 다운로드는 계속됩니다.
- 다운로드 크기와 SHA-256 체크섬을 검증하고, 설치 파일을 열기 직전에도 무결성을 확인합니다. 실패하거나 취소한 부분 파일은 제거합니다.
- 다운로드 안내를 6개 언어로 제공하고 사용자 가이드를 갱신했습니다.

## 호환성 및 데이터

- macOS 13 이상: Apple Silicon ARM64와 Intel x64. Windows 10/11: x64.
- 기존 프로젝트, 설정, 데이터 형식과 앱 식별자를 유지합니다.
- Git은 별도 설치가 필요합니다. Node.js는 앱에 포함되어 있습니다.

## 다운로드

- Apple Silicon: `pGit-1.3.0-macos-arm64.dmg`
- Intel Mac: `pGit-1.3.0-macos-x64.dmg`
- Windows: `pGit-1.3.0-windows-x64-setup.exe`
- Mac ZIP 파일과 `SHA256SUMS.txt`도 제공합니다.
- 1.2.0 이하에서는 이번 버전을 릴리즈 페이지에서 내려받아 설치하세요. 앱 내 다운로드는 1.3.0부터 다음 업데이트를 받을 때 사용할 수 있습니다.

## 검증

- 로컬 단위 테스트 123개, UI 시나리오 44개, macOS 실제 Electron 실행·다운로드 IPC·Git 작업·세션 복원 검사 통과.
- 다운로드 취소·재시도, 손상된 파일 차단, 6개 언어와 밝은/어두운 테마를 확인했습니다.
- 배포 Actions에서 macOS Developer ID 서명·공증·Gatekeeper 검사와 Windows 설치·앱 실행 검사를 수행한 뒤 게시합니다.
- [PR #21](https://github.com/Polar-Little-Lab/pGit/pull/21) · [배포 Actions](https://github.com/Polar-Little-Lab/pGit/actions/workflows/release-macos.yml)

## 알려진 제한

- 업데이트 확인과 다운로드는 사용자가 실행합니다. 설치 파일을 자동 실행하거나 앱을 자동 교체하지 않습니다.
- 앱 종료 시 진행 중인 다운로드는 취소됩니다. 이어받기는 제공하지 않으며 재시도하면 처음부터 받습니다. 완료된 파일은 다운로드 폴더에 남습니다.
- 브라우저 모드에서는 업데이트 확인·다운로드를 제공하지 않습니다.
- Windows 게시자 서명은 적용하지 않았습니다. SmartScreen 경고가 표시될 수 있습니다.
- Windows 설치 검사는 CI 기준이며 Windows 10/11 실기기 수동 검증을 대신하지 않습니다. Mac 실행 검사는 러너 아키텍처 기준입니다.
