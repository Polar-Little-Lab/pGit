## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.14-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.14-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.14-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 첫 실행 홈에 커밋 그래프 예시와 열기·복제·새 저장소 시작 카드를 제공합니다.
- 빨간 번호가 붙은 예제 화면으로 저장소 준비, 이력 확인, 변경 선택, 커밋과 공유를 안내합니다.
- 시작 가이드의 화면 확대, 이전·다음 이동, 이어보기와 다시 보기를 지원합니다.
- 프로젝트가 있는 홈에는 저장소·그룹 현황, 가이드 카드, 최근 프로젝트를 표시합니다.
- 메뉴 제거 및 설정 → 앱 정보, 커밋 이력 정리 안내 개선을 포함합니다.

- 첫 실행에서도 하단의 새 그룹 버튼으로 프로젝트 그룹을 미리 만들 수 있습니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
