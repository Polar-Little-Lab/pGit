## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.20-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.20-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.20-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 프로젝트 탭 상단의 그룹 색상이 테마의 일반 테두리 색상에 덮이던 문제를 수정했습니다.
- Java 그룹의 주황색을 비롯한 그룹 색상이 선택·비선택 탭 모두 유지됩니다.
- 상단 색상 표시와 그룹 설정의 탭 미리보기를 2px로 맞췄습니다.
- Windows·macOS 화면 설정과 6개 테마에서 선택·비선택 탭의 그룹 색상을 검증했습니다.
- 새 파일 생성, 작업 검색 별칭, 어두운 테마 대비 개선과 밝은 테마 화면 44장으로 갱신한 사용 가이드를 포함합니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
