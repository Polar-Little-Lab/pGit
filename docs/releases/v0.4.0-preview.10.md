## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.10-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.10-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.10-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 사용 가이드 전체 재작성: 24개 장, 최신 화면 41장, 빨간 테두리·번호·화살표로 클릭 순서 안내.
- Windows 줄바꿈에서도 가이드 이미지가 표시되도록 수정.
- 그룹 추천 목록 정리 및 네이버페이 N·토스·GLN 심볼 표시 개선.
- 원격 저장소가 하나면 로컬 브랜치와 정렬하고, 여러 개일 때만 추가 들여쓰기.
- Diff에서 줄·블록을 직접 선택하는 부분 스테이징.
- 전체 이력 검색과 파일 이력의 넓은 공통 화면, 검색 결과에서 커밋 이동.
- 커밋 이력 정리의 범위 선택·편집·결과 미리보기 개선.
- 복제 진행률, 커밋 무한 스크롤, 프로젝트 그룹과 탭 탐색 개선.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
