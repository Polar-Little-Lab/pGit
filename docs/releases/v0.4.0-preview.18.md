## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.18-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.18-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.18-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 변경 사항과 작업 검색에 **새 파일**을 추가했습니다. 저장소 안의 경로와 내용을 입력하면 필요한 폴더와 파일을 만들며, 기존 파일은 덮어쓰지 않습니다.
- 작업 검색에서 파일 추가·파일 생성·브랜치 추가·커밋 제목 수정 등 다양한 표현과 Git 명령어를 사용할 수 있습니다. 별칭은 화면에 노출하지 않으며 띄어쓰기와 영문 대소문자를 구분하지 않습니다.
- 어두운 테마의 변경 목록, 선택 파일명, 스테이징 버튼, 커밋 상세 입력란과 비활성 버튼 대비를 개선했습니다.
- 새 파일 생성과 검색 별칭을 사용 가이드에 추가하고, 밝은 테마의 실제 화면을 빨간 번호 안내와 함께 다시 촬영했습니다.
- 파일 생성·중복 방지·스테이징, 여섯 테마 대비, 작업 검색 및 기존 부분 커밋 흐름을 검증했습니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
