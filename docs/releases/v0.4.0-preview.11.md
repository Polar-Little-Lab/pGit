## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.11-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.11-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.11-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 커밋 이력 정리 상단에 정리 가능한 커밋 수와 제한 이유를 표시합니다.
- 병합 커밋·첫 커밋·100개 제한 등 선택할 수 없는 이유를 각 행에서 확인할 수 있습니다.
- 정리 가능한 범위가 없으면 실행 버튼을 숨깁니다.
- 일반 병합과 Squash의 차이, 메시지만 수정하는 방법, 적용 전 조건을 안내합니다.
- 병합 직후와 병합 이후 일반 커밋이 추가된 경우를 자동 검사합니다.
- 이전 버전의 가이드·아이콘·부분 스테이징 개선을 포함합니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
