## pGit 1.0.0

Windows와 macOS에서 로컬 저장소의 변경을 검토하고 커밋·브랜치·원격 작업을 수행하는 pGit의 첫 정식 릴리스입니다.

## 다운로드

- **Windows 10/11 · 64비트:** `pGit-1.0.0-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-1.0.0-macos-arm64.dmg`
- **Mac · Intel:** `pGit-1.0.0-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 주요 기능과 개선

- 프로젝트 탭과 그룹, 로고와 그룹 색상으로 저장소를 구분합니다. Java 등의 그룹 색상이 선택·비선택 탭 상단에 모두 유지되도록 수정했습니다.
- 커밋 그래프, 이력 검색, 파일 이력과 변경 전후 비교를 제공합니다.
- 파일·블록·줄 단위 스테이징으로 필요한 변경만 커밋할 수 있습니다.
- pGit 안에서 새 텍스트 파일과 필요한 폴더를 만들고 파일을 편집할 수 있습니다. 기존 파일은 덮어쓰지 않습니다.
- 작업 검색은 파일 추가·브랜치 추가·커밋 제목 수정 등 여러 표현을 인식합니다.
- 브랜치·병합·충돌 해결·커밋 메시지 수정·선형 커밋 이력 정리와 Stash·Worktree 작업을 제공합니다.
- 어두운 테마의 변경 목록·선택 행·버튼 대비를 개선했습니다.
- 밝은 테마의 실제 화면 44장과 빨간 번호 안내가 있는 24개 장의 사용 가이드를 포함합니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요하며 앱에서 설치 안내와 설치 확인을 제공합니다. 기존 pGit 사용자는 앱을 종료하고 새 설치 파일로 업데이트하세요.

Windows 게시자 인증서 서명과 Apple 공증은 아직 적용되지 않았습니다. 운영체제에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들·실행 검사, Windows 설치 프로그램 자동 설치·실행 검사를 수행합니다. Windows 자동 검사는 Windows Server 2022에서 수행하며 Windows 10/11 실기기 수동 검증을 대신하지 않습니다.
