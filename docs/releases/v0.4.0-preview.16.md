## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.16-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.16-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.16-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- Git 설치 안내와 설치 확인을 순서가 명확한 두 단계로 구성했습니다.
- Git 준비 중에는 복제 입력란과 실행 버튼을 잠시 숨기고 입력값을 보존합니다.
- 확인 실패 메시지는 확인 버튼 아래에 표시합니다.
- 확인 성공 시 Git 버전과 입력한 작업으로 돌아가기 버튼을 제공합니다.
- 밝은·어두운 테마와 좁은 화면에서 안내 배치를 개선했습니다.
- 밝은 테마 가이드 41장, 시작 가이드와 홈 화면 개선을 포함합니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
