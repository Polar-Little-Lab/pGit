## 다운로드

- **Windows 10/11 · 64비트:** `pGit-0.4.0-preview.15-windows-x64-setup.exe`
- **Mac · Apple Silicon(M1 이후):** `pGit-0.4.0-preview.15-macos-arm64.dmg`
- **Mac · Intel:** `pGit-0.4.0-preview.15-macos-x64.dmg`
- Mac ZIP 파일과 무결성 확인용 `SHA256SUMS.txt`도 제공합니다.

## 이번 버전

- 사용 가이드 41장을 밝은 테마의 최신 화면으로 다시 촬영했습니다.
- pGit 시작 가이드 카드의 글자와 대비를 개선하고 첫 화면에서 바로 보이도록 배치했습니다.
- 홈 예시를 검색 기능 구현 → 테스트 → main 병합으로 정리했습니다.
- 선택한 커밋과 src/search.ts 코드 변경이 연결되도록 개선했습니다.
- 4단계 시작 가이드와 프로젝트 홈, 메뉴 제거 및 앱 정보 개선을 포함합니다.

## 설치 및 검증

Node.js는 앱에 포함됩니다. Git은 별도 설치가 필요합니다. Windows는 Git for Windows, macOS는 Git 또는 Xcode Command Line Tools를 설치하세요.

Windows 게시자 인증서 서명 및 Apple 공증은 아직 적용되지 않은 프리뷰입니다. OS에서 확인되지 않은 앱 안내가 나타날 수 있습니다.

Git 기능 및 UI 자동 검사, macOS 번들 검사·실행 검사, Windows 설치 프로그램의 자동 설치·실행 검사를 거친 파일입니다. Windows 자동 검사는 Windows Server 2022에서 수행하며, Windows 10/11에서의 수동 검증을 대신하지 않습니다.
