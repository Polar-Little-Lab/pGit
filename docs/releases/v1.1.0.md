# pGit 1.1.0

Electron 런타임과 설치 파일 빌드 도구를 갱신한 보안 업데이트입니다.

## 다운로드

| 운영체제 | 설치 파일 |
|---|---|
| Windows 10/11 · x64 | [Windows 설치 프로그램](https://github.com/Polar-Little-Lab/pGit/releases/download/v1.1.0/pGit-1.1.0-windows-x64-setup.exe) |
| macOS 13 이상 · Apple Silicon | [Mac ARM64 DMG](https://github.com/Polar-Little-Lab/pGit/releases/download/v1.1.0/pGit-1.1.0-macos-arm64.dmg) |
| macOS 13 이상 · Intel | [Mac x64 DMG](https://github.com/Polar-Little-Lab/pGit/releases/download/v1.1.0/pGit-1.1.0-macos-x64.dmg) |

Mac ZIP 파일 및 SHA256SUMS.txt는 릴리스 첨부 파일에서 받을 수 있습니다.

## 변경 사항

- Electron 40.0.0 → 45.3.1, electron-builder 26.0.12 → 26.18.0으로 갱신했습니다.
- npm audit 기준 Critical 1개·High 13개를 제거했습니다. 이 수치는 하위 의존성 영향이 전파된 패키지 항목 수이며, 실제 악용 가능한 취약점 수와 같지 않습니다.
- 빌드 도구의 minimatch에서 파생되는 Moderate 6개 항목은 남아 있습니다. 호환성을 확인하지 않은 강제 메이저 override나 구버전 다운그레이드는 적용하지 않았습니다.
- 이력 검색 결과·전체 커밋 수 문구의 영어·일본어·중국어·스페인어·프랑스어 번역 누락을 수정했습니다.
- 백그라운드 조회와 탭 닫기가 겹칠 때 서버 작업 공간이 남는 문제를 수정했습니다. 닫기 성공 후 탭을 제거하고 일시적인 충돌은 재시도합니다.
- 매일 npm Dependabot 업데이트와 개발 의존성을 포함한 보안 검사를 추가했습니다. 패치·마이너 업데이트는 필수 플랫폼 검사와 보안 검사가 통과한 뒤 자동 병합합니다.
- Playwright를 1.65.0으로 갱신하고, checkout·setup-node·artifact 업로드/다운로드·Dependabot 메타데이터 Actions를 갱신했습니다.
- UI 검증의 Ubuntu 이미지를 Playwright가 지원하는 24.04로 고정하고, Windows 테스트 임시 폴더 삭제 시 잠금 재시도를 추가했습니다.

## 호환성 및 설치

- **macOS 13 Ventura 이상이 필요합니다. macOS 12는 이 버전에서 지원하지 않습니다.**
- Git은 별도 설치가 필요하며 Node.js는 데스크톱 앱에 포함됩니다.
- macOS 앱에 Developer ID 서명과 Apple 공증을 적용했습니다.
- Windows 설치 프로그램에는 게시자 인증서 서명을 적용하지 않았습니다.
- 기존 설정과 프로젝트 데이터를 삭제하는 변경은 포함하지 않았습니다.

## 릴리스 검증

이 릴리스는 macOS·Windows CI의 단위 테스트, 주요 UI 검사, 설치 파일 빌드 및 패키징된 앱 실행 검사가 성공한 뒤 게시됩니다. macOS 두 아키텍처의 번들 서명을 검사하고 러너 아키텍처에서 앱을 실행합니다. Windows 검증은 Server 2022 자동 설치·실행 기준이며 Windows 10/11 실기기 수동 검증을 대신하지 않습니다.

자세한 의존성 검토는 [보안 검토 기록](https://github.com/Polar-Little-Lab/pGit/blob/main/docs/SECURITY_REVIEW.md)을 참고하세요.
