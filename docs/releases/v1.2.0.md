# pGit 1.2.0

## 변경 사항

- 설정 → 앱 정보에 **최신 버전 확인**을 추가했습니다. 현재 설치 버전을 GitHub의 최신 정식 릴리즈와 비교하고, 새 버전이 있으면 릴리즈 페이지에서 설치 파일을 받을 수 있습니다.
- 앱 정보를 영어·일본어·중국어·스페인어·프랑스어로 설정해도 한국어로 표시되던 문제를 수정했습니다. 버전 안내와 업데이트 확인 결과도 선택한 언어로 표시됩니다.
- 최신 버전, 새 버전, 공개 릴리즈 없음, 연결 실패와 요청 제한을 구분해 안내합니다.

- 커밋 비교 창을 확대한 상태에서 이력이 갱신되면 창을 닫은 뒤 파일 비교가 사라지던 문제를 수정했습니다.

## 호환성 및 데이터

- macOS 13 이상: Apple Silicon ARM64와 Intel x64. Windows 10/11: x64.
- 기존 프로젝트와 설정을 유지합니다. 데이터 형식과 앱 식별자는 변경하지 않았습니다.
- Git은 별도 설치가 필요합니다. Node.js는 앱에 포함되어 있습니다.

## 다운로드

- Apple Silicon: `pGit-1.2.0-macos-arm64.dmg`
- Intel Mac: `pGit-1.2.0-macos-x64.dmg`
- Windows: `pGit-1.2.0-windows-x64-setup.exe`
- Mac ZIP 파일도 제공합니다. Mac에서는 DMG를 열어 앱을 응용 프로그램 폴더로 복사하고, Windows에서는 설치 프로그램을 실행하세요.
- `SHA256SUMS.txt`와 다운로드 파일의 SHA-256 값을 비교해 무결성을 확인할 수 있습니다.

## 검증

- 로컬 단위 테스트 118개, UI 시나리오 43개, macOS Electron 앱 실행·설정·프로젝트 복원 검사 통과.
- 6개 언어, 업데이트 결과별 표시, 오류 후 재시도, 실제 GitHub 조회를 확인했습니다.
- 배포 파일은 Actions에서 빌드·실행 검사를 통과한 뒤 게시합니다. macOS는 Developer ID 서명, 공증 티켓, Gatekeeper 검증을 수행합니다.
- [PR #18](https://github.com/Polar-Little-Lab/pGit/pull/18) · [배포 Actions](https://github.com/Polar-Little-Lab/pGit/actions/workflows/release-macos.yml)

## 알려진 제한

- 업데이트 확인은 수동으로 실행합니다. 자동 다운로드나 자동 설치는 제공하지 않습니다. 브라우저 모드에서는 사용할 수 없습니다.
- Windows 게시자 서명은 적용하지 않았습니다. 설치 시 SmartScreen 경고가 표시될 수 있습니다.
- Windows 설치 검사는 CI 기준이며 Windows 10/11 실기기 수동 검증을 대신하지 않습니다. Mac 실행 검사는 러너 아키텍처 기준입니다.
