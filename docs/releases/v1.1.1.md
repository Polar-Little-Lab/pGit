# pGit 1.1.1

설치 파일 빌드 도구의 minimatch 서비스 거부 취약점(GHSA-g3hv-75wg-m249)을 해결한 보안 유지보수 릴리스입니다.

- 취약한 minimatch 9.x·10.x 경로에만 11.0.1 override를 적용했습니다. 영향을 받지 않는 3.x·5.x 경로는 유지합니다.
- 개발 의존성을 포함한 npm audit 결과를 Moderate 6개에서 전체 0개로 줄였습니다. 기존 6개는 동일한 취약점의 상위 패키지 전파를 포함합니다.
- Electron 45.3.1과 electron-builder 26.18.0은 유지합니다.
- macOS ARM64·Intel 설치 파일은 GitHub Actions에서 Developer ID 서명과 Apple 공증 후 검증합니다.
- Windows x64 설치 프로그램은 기존과 같이 게시자 인증서 서명이 없습니다.
- 기존 프로젝트·설정 데이터는 유지합니다. macOS 13 이상이 필요합니다.

이 릴리스는 macOS·Windows 패키징, 주요 UI 및 패키징된 앱 실행 검사를 통과한 뒤 게시됩니다. 설치 파일과 SHA256SUMS.txt는 아래 첨부 파일에서 받을 수 있습니다.
